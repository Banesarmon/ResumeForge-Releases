# ResumeForge Releases

This public repository is the **download and automatic-update channel** for the ResumeForge Windows desktop application.

The application source code is maintained privately in `Banesarmon/ResumeForge`. This repository is for *release artifacts only*; do not upload personal resumes, draft documents, job application data, passwords, API keys, or development secrets.

**Status:** No downloadable release has been published yet.

When the first update is ready, use the [Releases page](https://github.com/Banesarmon/ResumeForge-Releases/releases) to publish a tagged version (such as `v0.5.0`) with both `ResumeForge_Windows.zip` and `ResumeForge_Windows.zip.sha256`.

The application checks GitHub's `releases/latest` endpoint, compares version numbers, verifies the ZIP checksum, and requests confirmation before installing.
